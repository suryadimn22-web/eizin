# e-Izin MAN 2 Kota Pekanbaru

Aplikasi pengajuan, persetujuan, dan rekap izin siswa (keluar sekolah sementara, pulang lebih awal, dispensasi lomba/kegiatan).

- Aplikasi: https://suryadimn22-web.github.io/eizin/
- Data & rekap: Google Spreadsheet "e-Izin MAN 2 Kota Pekanbaru" (akun madrasah)
- `backend/Code.gs`: salinan kode Apps Script (cadangan; yang berjalan ada di Spreadsheet)

Bisa dipasang di layar utama HP dan dipakai offline oleh admin (Waka); data tersinkron otomatis saat online.
